# Marina Berdysheva — Portfolio v10

## Управление контентом

Откройте `/editor.html` на запущенном сайте (например, `http://localhost:4321/editor.html`).
Выберите язык и текстовое поле, измените текст; для галерей выберите категорию и добавьте URL медиа.
Экспортируйте JSON кнопкой «Сохранить JSON», замените `public/content/site.json` скачанным файлом.

Для своих изображений: поместите файлы в `public/uploads/` и в редакторе указывайте `/uploads/имя.webp`.
Файлы изображений НЕ помещаются в JSON автоматически — их нужно отдельно скопировать в проект.
Изображения и тексты публикуются после коммита в GitHub и деплоя.
До подключения CMS это файловый редактор, а НЕ облачная админка.

`featured: true` отмечает крупную работу (две колонки на широком экране); все остальные фото определяют высоту плитки по исходным пропорциям. Порядок можно менять в редакторе.

## Запуск
`npm install` → `npm run dev` → откройте `/editor.html`.
Проверки: `npm run check:syntax` и `npm run build`.

Временные примеры используют Unsplash. Не публикуйте их как собственные работы. Форма обратной связи не отправляет сообщения.

Вкладка «Обложки» позволяет менять главную фотографию и карточки категорий/услуг. Все переводы RU / EN / TH доступны во вкладке «Все тексты».

Редактор — файловый: сам по себе он не загружает фотографии на сервер и не публикует изменения. Сохраняйте копию JSON перед изменениями.

## Публикация на Cloudflare Pages

Статический Astro-сайт. Основная ветка: `main`. Node.js: 22 (см. `.node-version`).

- Установка для воспроизводимой сборки: `npm ci`.
- Команда сборки Pages: `npm run build`.
- Каталог результата: `dist`.
- Корень проекта: корень репозитория.
- Серверный адаптер, секреты и переменные окружения не требуются.
- Подключите GitHub-репозиторий через Pages Git integration: каждый коммит в `main` запускает публикацию.

## Содержимое и конфиденциальность

Изображения Unsplash и названия брендов — демонстрационные примеры, а не работы автора или список клиентов. На сайте это обозначено отдельно. Права на сторонние изображения принадлежат их правообладателям.
Личный телефон и ссылки на личные мессенджеры исключены до явного согласования публикации.
Нельзя добавлять в репозиторий пароли, токены, `.env`, приватные фотографии и несогласованные контакты.

`/editor.html` — публичный локальный редактор JSON, не админка: посетитель не может изменить сайт на сервере. Изменения становятся общими только после загрузки обновлённого JSON в GitHub.
Форма не передаёт введённые данные на сервер: она готовит текст для копирования. Получателя и отправку нужно подключить отдельно.
